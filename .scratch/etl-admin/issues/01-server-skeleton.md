# 01: 服务骨架与内嵌 UI

**What to build:** 一个可启动的 `datax-server` 二进制：加载配置与数据目录，默认监听 `127.0.0.1:8080`，提供无需认证的健康检查，并把前端构建产物内嵌在二进制中提供，前端子路由回退到 `index.html`。同时打通构建链：一次构建同时产出 `datax` 与 `datax-server`，开发模式下前端可代理 API 到本地服务。本票据不包含登录，登录在下一票据关闭；此阶段没有任何业务数据端点。

**Blocked by:** None (can start immediately)

**Status:** done
