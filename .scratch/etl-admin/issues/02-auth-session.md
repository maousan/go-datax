# 02: 登录与会话

**What to build:** 管理台必须登录后才能使用。服务端从配置文件读取唯一 AdminUser 的用户名与密码（bcrypt 哈希或明文），登录成功签发 JWT；首次启动自动生成随机密码与签名密钥并写入配置文件，控制台只打印一次密码。前端提供登录页、持久化 token、401 后跳转登录并支持登录后回到原页面，以及显式登出。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 配置文件不存在时自动生成随机用户名与密码、随机签名密钥，并以仅当前用户可读写的权限写入
- [ ] 生成的密码只在控制台打印一次，之后不再出现
- [ ] 密码支持 bcrypt 哈希与明文两种形式，均有测试覆盖
- [ ] 提供生成密码哈希的命令行能力
- [ ] 登录成功返回 JWT（HS256，默认 12 小时过期），会话查询返回用户名与过期时间
- [ ] 未携带、无效或过期 token 访问任何业务 API 返回 401
- [ ] 登录页在凭证错误时显示统一错误，不泄露账号是否存在
- [ ] 前端把 token 持久化，刷新页面保持登录；收到 401 清除 token 并跳转登录页
- [ ] 登录成功后回到进入登录页之前的目标页面
- [ ] 登出清除本地 token 并返回登录页
- [ ] 服务重启后未过期 token 仍然有效（签名密钥已持久化）
- [ ] API 层测试覆盖登录、鉴权中间件、过期与错误凭证
