# 07: 运行核心（成功/失败、状态、单飞与并发上限）

**What to build:** AdminUser 可以从任务页面启动一次 JobRun。服务端先展开并校验配置、写入 Run Snapshot，再以 `datax -job <snapshot>` 子进程执行；运行状态、退出码、耗时与错误摘要被记录，日志落盘。同一 SyncJob 不允许并发，全局最多两个运行；服务重启后残留的运行被标记为失败。服务启动时校验 datax 二进制并记录版本。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 在任务列表或详情点击运行即可启动，接口返回运行标识
- [ ] 启动时生成 Run Snapshot 并持久化，快照内容等于该次实际执行配置
- [ ] 配置展开或校验失败时不创建运行，返回可读错误
- [ ] 子进程正常退出时状态为成功，非零退出码为失败
- [ ] 运行记录包含开始/结束时间、耗时、退出码与错误摘要（失败时取日志尾部有意义内容）
- [ ] 每次运行的日志完整写入独立日志文件
- [ ] 同一 SyncJob 已运行时再次启动返回冲突，界面能显示原因
- [ ] 全局运行数达到上限时返回明确错误，界面能显示原因
- [ ] 服务启动时若存在残留的运行中记录，统一置为失败并说明原因
- [ ] 启动时校验 datax 二进制存在且可执行，缺失则清晰报错；健康检查可显示解析到的 datax 版本
- [ ] 测试使用假 datax 二进制覆盖成功、失败、慢任务与残留恢复
