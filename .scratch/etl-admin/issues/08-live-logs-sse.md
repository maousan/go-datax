# 08: 实时日志（SSE）

**What to build:** AdminUser 打开运行详情即可实时看到日志：先回放已产生的日志，再持续跟随；运行结束时状态自动更新。日志视图默认粘底滚动，向上滚动时暂停跟随，断线后自动重连并从上次位置续传。
