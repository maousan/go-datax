# 09: 取消运行

**What to build:** AdminUser 可以停止运行中的 JobRun。服务端终止整个子进程树，运行状态置为已取消，日志保留；重复取消是幂等的，已结束的运行不可取消。取消后该 SyncJob 的单飞锁释放，可以立即再次启动。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 运行中的详情页与列表提供停止操作
- [ ] 停止后子进程及其子进程被终止（Windows 与 Unix 均需正确实现）
- [ ] 运行状态变为已取消，结束时间与耗时被记录
- [ ] 已取消运行的日志文件保留且可查看
- [ ] 对已取消或已结束的运行再次取消返回幂等的成功结果或明确提示
- [ ] 取消不存在的运行返回明确错误
- [ ] 取消成功后同一 SyncJob 可以立即再次启动，不被单飞限制阻塞
- [ ] 测试使用慢速假二进制覆盖取消、幂等与锁释放
