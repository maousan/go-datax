# 10: 运行历史与概览

**What to build:** AdminUser 可以在运行历史中分页浏览所有 JobRun，并按 SyncJob、状态与时间范围过滤；运行详情展示耗时、退出码与错误摘要，并可下载日志与查看快照。概览页展示数据源与任务数量、最近运行与成功率。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 运行历史支持分页，展示任务名、状态、开始时间、耗时
- [ ] 可按 SyncJob、状态与时间范围过滤
- [ ] 运行详情展示状态、开始/结束时间、耗时、退出码与错误摘要
- [ ] 运行详情可下载完整日志文件
- [ ] 运行详情可查看并下载 Run Snapshot
- [ ] 删除 SyncJob 后其历史运行仍然展示原任务名
- [ ] 概览展示数据源数量、任务数量与最近运行列表
- [ ] 概览展示所选时间窗口内的成功率
- [ ] 从概览的某次运行可以直接进入运行详情
- [ ] API 层测试覆盖分页、过滤、详情、下载与删除任务后的历史展示
