# 管理配置以数据库为事实源，并为每次运行保存快照

管理台不直接编辑磁盘上的 DataX 作业文件，而是把 SyncJob 保存在元数据库里，启动 JobRun 时再固化成一份完整的 Run Snapshot 交给执行器。这样表单模式可以用 DataSource 引用避免凭据重复，Raw mode 仍能保存任意 DataX JSON 以保住 100% 兼容；快照则保证历史运行可复现，即使任务定义后来被修改。

**Considered Options**: 直接以文件为事实源（与 DataX 习惯一致，但无法做引用、校验和并发控制）；只在内存中解析不落快照（排障时无法确认当时实际执行的配置）。

**Consequences**: 快照中包含已展开的连接凭据，必须依赖数据目录的文件权限保护；任务与数据源的删除需要定义引用约束。
