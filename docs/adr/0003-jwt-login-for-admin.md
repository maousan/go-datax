# 管理台始终启用登录，账号凭据来自配置文件

即使是单机部署、监听 `127.0.0.1`，管理台也要求登录：账号与密码哈希放在服务端配置文件，登录后签发 JWT（HS256，默认 12 小时）。这样本机与远程访问只存在一条鉴权路径，不会因为"本机免登录"留下安全盲区；JWT 则允许服务重启后无需重新配置会话。

**Considered Options**: 仅非回环绑定时登录（本机体验更好，但形成双路径与盲区）；服务端内存会话令牌（可即时吊销，但重启全部失效，与持久化登录偏好冲突）。

**Consequences**: MVP 不支持服务端主动吊销 JWT，登出仅清除前端 token；令牌过期时间与签名密钥必须通过配置管理。
